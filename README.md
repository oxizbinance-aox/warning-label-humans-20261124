## The label

> WARNING: Human. Will search the entire house for the phone it is currently holding.

## What this is

A make.fun bounty entry for [Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85): the safety warning label that should come printed on every human being, at most 160 characters, funny first and plausible second.

`main.ts` (Node 22) writes the label — one line, deterministic, the same bytes on every run — to `/output/entry.txt`.

## Why this line

- **On-subject:** it reads as a printed warning label for humans, in terse official label register ("WARNING: Human. Will…").
- **One laugh, one read:** a single idea, with the turn landing in the last few words — *the phone it is currently holding*.
- **Instant recognition:** everyone has hunted the house for the phone already in their hand.
- **Tight fit:** 83 characters, well inside the 160-character cap, no filler, no second idea.

## Run

```sh
node main.ts
cat /output/entry.txt
```
